# Подключение к хабу

Хаб соединяет агентов на разных машинах (PLAN.md, v2). Без него шина
остаётся локальной, как раньше. Полное описание установки хаба появится на
этапе 13. Пока здесь только то, что нужно агенту, чтобы подключиться к уже
развёрнутому хабу.

## Что выдаёт администратор хаба

`agent-bus admin agent add <агент> --team <команда>` и
`agent-bus admin token rotate <агент>` печатают всё нужное одним блоком:
адрес хаба, имя агента, токен и команду, которая сохраняет токен на машине
агента. Блок передаётся владельцу агента по закрытому каналу. В нём есть:

- **Адрес хаба:** `https://….execute-api.eu-central-1.amazonaws.com`.
- **Имя агента.** Оно задано на хабе, и `agent_name` плагина должен
  совпадать с ним.
- **Токен `ab_…`.** Его показывают один раз, на хабе хранится только хеш.
- **Команда или команды, в которые входит агент.** Писать можно только
  тиммейтам.

## Настройка

1. Укажите адрес хаба в опции плагина `hub_url`. В окружении её заменяет
   `AGENT_BUS_HUB`.

   ```bash
   claude plugin configure agent-bus
   ```

2. Сохраните токен на машине агента командой из блока администратора.
   Копия репозитория для этого не нужна. Команда читает токен со stdin
   (вставьте его и нажмите Ctrl-D), чтобы он не попал в историю shell и в
   список процессов, и кладёт его в файл с правами 0600:

   ```bash
   AGENT_BUS_HUB=<адрес> AGENT_BUS_NAME=<агент> \
     uvx --from git+https://github.com/AndrewKolpakov/mcp-agent-bus agent-bus hub-token
   ```

   Файл лежит в `~/.agent-bus/hubs/<хост хаба>/<агент>/token`. Токен
   нельзя хранить в `userConfig`: опции плагина попадают в окружение
   каждого хука. Если файл читается кем-то, кроме вас, сервер откажется
   его использовать.

3. Запустите сессию так же, как для локальной шины: с `AGENT_BUS_SESSION=1`
   и с флагом канала. Без флага сессия на шине, но события к ней не
   приходят.

   ```bash
   AGENT_BUS_SESSION=1 claude \
     --dangerously-load-development-channels plugin:agent-bus@agent-bus-dev
   ```

## Как это работает на машине

- **Зеркало.** Сервер держит WebSocket к хабу и дописывает своё
  представление в `~/.agent-bus/hubs/<хост>/<агент>/log.jsonl`. Хуки и
  `agent-bus inbox` читают этот файл и в сеть не ходят. `agent-bus sync`
  догоняет зеркало вручную, когда сервер не запущен.
- **Проверка токена.** При старте сервер спрашивает хаб, чей это токен.
  Если токен принадлежит другому агенту, сессия остаётся вне шины и
  объясняет причину в инструкциях.
- **Хаб недоступен.** Чтение работает по зеркалу, отправка возвращает
  ошибку. Сервер переподключается сам.
